# Ügyfélportál – pancelbence.hu (prototípus)

Kattintható prototípus a fejlesztői átadáshoz és teszteléshez.

- `index.html` – a teljes alkalmazás egy fájlban
- `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` – telefonos „app” ikon és megjelenés

Az adatok a böngészőben (localStorage) tárolódnak, eszközönként külön.
Eszközök között a „Mentés” / „Visszatöltés” gombokkal vihetők át (JSON fájl).

Valódi ügyféladatot ebbe a prototípusba ne vigyél fel: a repó és az oldal nyilvános.
